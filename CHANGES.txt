pkgs/base/core_base-1+1.cpk: added.
  Move to base/ subdirectory to facilitate upgrade based installations,
  and to avoid clobbering existing installs by accident.

  Removed the root user profile aliases -i. As I filed with Red Hat, this is
  harmful. It encourages the use of -f to avoid the forced interaction, and
  this misses the warnings that would come from -r used without it. The
  aliases are thus removed from /etc/profile. This should be consistent
  for the base package and for the IUR CD-ROM's /etc/profile (which base
  package installation is actually different from the installed
  systems).

  The CorePKG metadata is distinct in its date and build values, which
  identifies the clear build change from the original Coredistro. The patch
  version in upgraded packages will remain at +1 regardless. The distribution
  is not maintained by updating packages. This is the responsibility of the 
  user. Thus, the user tracks their own patches by incrementing the patch
  number.

  Add /usr/bin/sh and /usr/man/man1/sh.1.bz2, removed from the Bash package.
  This allows another shell to be made the default by the user while still
  rebuilding or upgrading Bash. It was necessary to update /etc/passwd and
  the shebang lines of /etc/rc.d/ scripts.

  Modified /etc/man.conf to compensate for change of directory of less.

  Modified /etc/inittab to use /usr/bin/ path instead of /sbin/.

  Removed the lost+found/ directory. This is a file system related
  directory that should be at the base of a writable file system, thus
  removing it from the IUR, but also removing it from the core_base
  package as inappropriate. Also, the rr_moved/ directory exists but is
  not needed due to ISO level used when making the image, which indicates
  building the ISO should be done differently. It too is removed.

  The /usr/sbin/ directory is removed.

  In the future, /bin/ will be a symlink to /usr/bin/. Be aware that the
  kernel expects /bin/pwd for building from source. Some configure scripts
  hard link to /bin/sh so that is temporarily provided while building. The
  toolchain is also sensitive to this and to Bash's placement. Glibc builds
  of ldconfig and sln are static and left in /sbin/, but init is symlinked
  for compatibility.

pkgs/core_ncurses-5.3+1.cpk: rebuilt.
  Moved libraries to /usr/lib/. Maintain /lib/ symlinks for now.

  /usr/ was the original home directory, but an early research Unix DEC PDP
  disk fill required a second drive and things not related to booting were
  moved there under the idea of user land tools. Research Unix returned to
  using /bin/ and /lib/, leaving /usr/ to include files and home directories,
  but the idea of moving everything to /usr/ was in motion even in 2003. This
  begins looking at that change as the norm.

pkgs/core_e2fsprogs-1.29+1.cpk: rebuilt.
  This package uses /usr/bin/ for binaries, especially instead of /usr/sbin/.

  The /usr/sbin/ directory is superfluous. The /sbin/ directory is required on
  Linux by only a limited number of programs, (as one place checked by the
  kernel for init). /sbin/ was originally static binaries moved from /etc/
  for booting needs only. At this point, it too is superfluous, and rare
  packges even build static binaries (e.g. glibc). /usr/bin/ is favored over
  /bin/ with the expectation that /usr/ in general (e.g. not including
  /usr/local/) should remain on the root file system. This also means that the
  sbin/ directory restriction to execution by only the root user is
  effectively deprecated, a change in Core practice.

pkgs/core_binutils-2.13+1.cpk: rebuilt.
  Manual pages and info manuals are uncompressed in Devan's Core. Switch to
  Bzip2 compression for man pages, and Gzip for info manuals (due to lack of
  built-in support for Bzip2 compression with info).

  In general, build scripts rely on the existing strip capability of the
  Makefile (where recognized), or use --strip-unneeded as the common approach
  to binary stripping of debug and related symbols. Optimizing is for size,
  e.g. -Os: storage is a big deal for small systems.
